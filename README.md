# Spam Email Detection

This project implements a Machine Learning–based Spam Email Detection system that classifies emails as spam or non-spam (ham). It demonstrates text preprocessing, feature extraction, model training, and evaluation using a labeled email dataset.

## Project Overview

This project aims to automatically detect spam emails by applying supervised machine learning techniques on textual data. The system learns patterns from labeled emails and predicts whether a given email is spam or legitimate.

The project is implemented in Python using common data science and machine learning libraries.

## Project Structure

```text
SPAM-EMAIL-DETECTION
├── Code.ipynb        # Jupyter Notebook with data preprocessing, model training, and evaluation
├── mail_data.csv     # Dataset containing email text and labels
└── README.md         # Project documentation
```
